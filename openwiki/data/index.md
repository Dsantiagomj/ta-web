# Files

- [Achievement prose import](achievement-prose-import.md) - How pnpm import:achievement-prose reads Torre's Squarespace achievement pages, separates his intro and outro prose from the template lists the new page computes, uploads screenshots and video posters once, and writes the two rich text fields under the importSnapshot rule so reruns never undo panel edits.
- [Importing Torre's achievement pages](achievements-import.md) - The pnpm import:achievements script that copies Torre's current metalogros index (order, names, slugs, states, hand-picked representatives and loose guides) onto the metalogros and achievement pages, the pnpm fix:achievements script for targeted corrections afterwards, their dry-run default, database guard and tests.
- [Database and migrations](database.md) - How the app picks its Postgres connection (pooled, direct or the embedded dev database), when Payload pushes the schema versus applying committed migrations, and how to change the schema safely.
- [Inventory and delta import](delta-import.md) - How pnpm import:inventory downloads a new copy of Torre's Squarespace site and finds what changed page by page, and how pnpm import:delta brings those changes into ta-web without undoing his panel edits.
- [Importing Torre's Dofus guides](dofus-guides-import.md) - How pnpm import:dofus-guides reads each Dofus page of Torre's Squarespace site, links its achievements, quests and items, fetches missing items and video posters, and creates or updates the dofus-guides collection without overwriting what Torre changed in the panel.
- [DofusDB game data refresh](dofusdb-refresh.md) - How pnpm data:refresh, the weekly Railway task and the panel's «Traer ahora» refresh every game data collection from the public DofusDB API in one logged, single-at-a-time run, how the client retries, how quests, prerequisites, level-200 rewards, level tiers and needs are derived, why a rerun changes nothing, how failed rows are counted, how writes run several at a time, and how to run it without touching production by accident.
- [Quest guide rewards](guide-rewards.md) - How a quest guide stores its rewards as fields Torre edits (XP, minimum XP, kamas, items, level tiers and other rewards) beside the Squarespace text, how the guide header picks between them and DofusDB, and the one-off maintenance scripts that filled and cleaned them (guides:rewards, guides:rewards-dofusdb, guides:reward-typos, guides:shown-items).
- [Squarespace import](squarespace-import.md) - How the Squarespace import reads a cached Squarespace page, orders its blocks, and turns it into a quest guide draft (summary, start NPC, body blocks, oddities), how prose becomes Payload's Lexical rich text, and how pnpm import:guides loads the guides and their images into Payload as drafts.
- [Torre corrections to DofusDB data](torre-corrections.md) - The «Corrección de Torre» group on quests, items, monsters, dungeons, NPCs and achievements, which lets Torre override a name, level or image, or hide a record, without editing DofusDB's data; how writes are scoped so the panel edits only the correction and the refresh never does, and how every page applies it.
